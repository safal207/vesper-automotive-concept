# VESPER / 01 — portfolio case

## Problem

Make a visual idea tangible through a small interactive experience that can be explored without an account.

## Contribution

- Four visual grading treatments on one original render
- Three detail views with accessible pressed states
- JSON export of selected finish and detail
- Responsive editorial layout and reduced-motion support

Code and vector artwork are original project work, created with AI assistance. VESPER uses an original AI-generated fictional vehicle render.

## What a reviewer can try

1. Four visual grading treatments on one original render.
2. Three detail views with accessible pressed states.
3. JSON export of selected finish and detail.
4. Responsive editorial layout and reduced-motion support.

## Verification boundary

- Node syntax, static local asset links and anchor targets checked by scripts/verify.mjs.
- Room Control additionally checks persisted-state sanitization, preset isolation and watt estimates.
- Layer Lab additionally checks palette/export consistency and hidden-layer exclusion.
- No real browser, mobile screenshot or WebGL runtime verification was available during this build.
- No performance, conversion, revenue or client-use results are claimed.

## Product scope

- Fictional visual concept, not a production automobile.
- Finish selection is image grading, not a physically accurate paint configurator.
- No engineering specifications, customers or commercial results are claimed.
